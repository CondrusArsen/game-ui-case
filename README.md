# Lumen Tides — UI/UX кейс мобильной игры

Интерактивный прототип интерфейса мобильной игры: главная с ивентами, карта уровней, старт уровня с бустерами, экран победы, магазин с офферами и покупкой, боевой пропуск. Переходы между экранами, микро-анимации, авто-тур.

**Кейс:** https://condrusarsen.github.io/game-ui-case/ · **Прототип:** https://condrusarsen.github.io/game-ui-case/app.html

Сделано с ИИ: прототип собран ИИ-агентом (Claude Code) в рабочем процессе Арсения Атрохова. Стек: HTML, CSS, vanilla JS. Игра, названия и цены вымышлены, покупки ненастоящие.
